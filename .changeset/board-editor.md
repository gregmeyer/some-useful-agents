Boards can be arranged: drag, resize, keyboard, add and remove, Save and Undo.

Open Pulse or a named dashboard with **Board view**, press **Edit**, and move tiles by dragging (or with the arrow keys), resize them from the corner (or Shift+arrows), add headings, notes and agent tiles, and place Pulse's tiles from the Unplaced tray. Changes save together with **Save**; **Undo last save** puts the previous layout back, and a save from a stale copy of the board is refused instead of overwriting a newer layout. Pulse's board can start from the arrangement your browser kept for the old Pulse.
