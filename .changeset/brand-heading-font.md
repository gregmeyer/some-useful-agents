Brands can change the heading font, and a used brand is kept under Your brands.

A brand made with Update my brand looked like sua's default because headings, titles and labels stayed in sua's monospace: brands could only set the text and code fonts. There's now a heading font (`fonts.display`, a `--font-display` token that defaults to the code font, so sua's own look doesn't change); headings, titles and labels use it, while codes and data stay monospace. The brand maker sets it from the site and is told to take surfaces, borders and corners from the brand too, and the editorial preset has its own. Choosing **Use this brand** now also saves it under **Your brands** (marked In use, with Delete), and **The look in use** names it.
