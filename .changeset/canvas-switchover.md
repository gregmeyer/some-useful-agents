Pulse and dashboards are canvases: one A2UI surface each, arranged in place.

`/pulse` and `/dashboards/<id>` now draw the board as one A2UI canvas, with **✎ Arrange** (the outline editor: sections, grids, rows, tabs, cards, tiles) and **✨ Suggest a layout** (the planner's arrangement opens as unsaved changes) right on the page. Pulse shows what you've placed, then everything else in tabs by recent use. **Save as pack** exports the canvas, each section or tab becoming a pack section. The grid board editor from earlier previews is gone; boards saved with it open as canvases with the same sections and tile sizes. The previous layout is still one switch away for this release (Settings → Appearance).
