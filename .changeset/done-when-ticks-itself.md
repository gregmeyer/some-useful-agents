Done-whens that repeat a notebook's own work tick themselves.

A notebook's "done when" list was ticked only by hand, so notebooks whose work was done still read 1 of 4. Now a done-when about the decision ("A decision recorded") ticks when you decide, "At least N …" when that many options are in the running, "… sourced for each" when the source step reaches its goal, and one that names a check ("clean title") when every option you chose passes it. Hover one to see what ticks it. One you've ticked or unticked by hand is left as you set it.
