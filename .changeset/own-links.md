Each option's own page, not a search page.

Lists now aim for each option's own link (the listing, posting or product page). A find step's job asks agents for it, and sua's keeper leaves out a results page rather than file it as the link. A link several options share, or one shaped like a search page, shows as **Search page ↗**, never counts as two options being the same, and Where it stands says how many lack their own page. A source step can look up the link field, counting a search-page link as missing until it's replaced.
